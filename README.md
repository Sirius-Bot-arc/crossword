# Power Word Quest
Open `index.html` in a browser (needs internet once for the Tailwind CDN + Google Fonts).
Or run `python3 -m http.server` in this folder and visit http://localhost:8000.
- `js/scenes.js` : the three illustrated scenes + word/clue data (add levels here)
- `js/layout.js` : automatic crossword layout
- `assets/characters/` : drop licensed PNG cutouts here (see README inside)
