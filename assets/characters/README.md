# Character art slots

The game loads `goku.png`, `vegeta.png`, `piccolo.png`, `krillin.png` from this folder
(transparent PNG cutouts, full or 3/4 body, facing right, roughly 1:1.4 aspect ratio).
If a PNG is missing, it falls back to the matching original stand-in `.svg` in the same folder.

I can't ship licensed Dragon Ball artwork. To use your own properly licensed art, drop the PNGs here
with those exact names. Nothing else needs to change.
